## Design System

- **Brand color**: Teal (`teal-600` primary, `teal-400` dark mode accent)
- **Dark mode**: Class strategy via `next-themes`, `dark:bg-gray-900`
- **Typography**: System font stack, `tracking-tight` on headings
- **Spacing**: 8px baseline grid
- **Motion**: `cubic-bezier(0.16, 1, 0.3, 1)` for slide-up reveals
- **Navbar**: Glassmorphism (`backdrop-blur-md`, semi-transparent bg)
- **Accessibility**: All interactive elements require `aria-label` + focus ring
- **Hover states**: `transition-colors duration-200` or `transition-transform`

| Production audit | `unspecified-high` | `production-audit` |

### Key Conventions for This Project

1. **Path alias**: `@/*` maps to project root — always use `@/components/...` imports
2. **Vercel serverless**: Default Next.js hosting on Vercel — SSR/ISR/API routes available if needed
3. **Dark mode**: Always test both `light` and `dark` variants of any component
4. **Accessibility**: Every interactive element needs `aria-label` and visible focus ring
5. **No test framework**: Project has no test runner configured — add Vitest or Jest before writing tests
6. **TypeScript strict**: `strict: true` — never use `as any`, `@ts-ignore`, or `@ts-expect-error`
7. **Impeccable skill**: Always run `node .opencode/skills/impeccable/scripts/context.mjs` before design work
